Κώδικας ενσωμάτωσης για https://sigrow.net/theseis/

Η σελίδα έχει ήδη το σημείο τοποθέτησης #theseis-embed (Elementor HTML widget, κλάση theseis-embed). Αντικαταστήστε το κείμενο-placeholder με μία από τις δύο παραλλαγές παρακάτω. Αντικαταστήστε το https://zizujr.github.io/sigrow-theseis αν τα αρχεία φιλοξενούνται σε άλλη διεύθυνση.

1. Iframe (με αυτόματο ύψος)

Επικολλήστε το στο HTML widget της καρτέλας «Ανοιχτές θέσεις». Το σκριπτ αλλάζει το ύψος του iframe και αφαιρεί το στυλ του placeholder.

<style>
#theseis-embed.theseis-embed {
  min-height: 0 !important;
  padding: 0 !important;
  display: block !important;
  text-align: left !important;
  background: transparent !important;
  border-radius: 0 !important;
}
</style>
<iframe
  id="sigrow-theseis"
  src="https://zizujr.github.io/sigrow-theseis/index.html"
  title="Ανοιχτές θέσεις και εξετάσεις οργανισμών"
  loading="lazy"
  referrerpolicy="no-referrer-when-downgrade"
  style="width:100%;border:0;display:block;background:transparent;min-height:320px;"
></iframe>
<script>
(function () {
  window.addEventListener("message", function (e) {
    if (!e.data || e.data.type !== "sigrow-theseis-height") return;
    var f = document.getElementById("sigrow-theseis");
    if (f && typeof e.data.height === "number") {
      f.style.height = Math.max(320, e.data.height) + "px";
    }
  });
})();
</script>

2. Εγγενής απόδοση (div + script)

Φέρνει το theseis.json και ζωγραφίζει τις κάρτες μέσα στο υπάρχον #theseis-embed, με τα typography και χρώματα του νέου design. Εναλλακτική, αν προτιμάτε να ζωγραφίζονται οι κάρτες μέσα στη σελίδα αντί για iframe. Το Elementor στη σελίδα επιτρέπει ήδη custom HTML/JS.

<link rel="stylesheet" href="https://zizujr.github.io/sigrow-theseis/theseis.css">
<script src="https://zizujr.github.io/sigrow-theseis/theseis.js" defer></script>
<script>
document.addEventListener("DOMContentLoaded", function () {
  if (window.SiGrowTheseis) {
    SiGrowTheseis.mount("#theseis-embed", {
      api: "https://zizujr.github.io/sigrow-theseis/theseis.json"
    });
  }
});
</script>

Αν το CSS/JS φορτώνει πριν υπάρξει το defer, μπορείτε εναλλακτικά να βάλετε το script στο τέλος του HTML widget χωρίς defer, αμέσως μετά το theseis.js.
